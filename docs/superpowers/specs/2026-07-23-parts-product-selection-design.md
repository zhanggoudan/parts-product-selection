# 配件选品 Skill V2 设计

## 目标

创建自动发现的 `parts-product-selection` Skill。用户贴产品图、Amazon ASIN，或两者一起提供时，Skill 以“新卖家能否进入”为中心给出可复核的配件选品结论。

## 输入与数据策略

- ASIN：优先使用卖家精灵网页端或已安全配置的 API，取得出单词、流量词、关键词指标及 PPC 竞价；再结合 Amazon 商品和评论。头部数据只用于验证需求和提取关键词，进入难度必须以中腰部／尾部卖家数据及保守的新卖家假设评估。
- 图片：识别产品类别、接口/尺寸/OEM 号等关键规格；若缺少 ASIN，输出预评分和待确认项，不能作正式主推结论。
- API：仅在本机 `SELLERSPRITE_SECRET_KEY` 已配置时调用。不得读取、打印或写入密钥。没有密钥时可用已登录网页端；若数据权限不足，明确标注限制。

## 新卖家进入评分模型（100 分）

| 维度 | 权重 |
| --- | ---: |
| 头部需求验证 | 15 |
| 头部关键词与用户痛点 | 10 |
| 中尾部卖家出单与价格带 | 15 |
| 新卖家 CPC／广告可行性 | 15 |
| 竞争与评论门槛 | 10 |
| 利润空间 | 15 |
| 适配／退货风险 | 10 |
| 差异化空间 | 5 |
| 评论质量 | 5 |

正式评分必须标明每项依据、数据层级（头部或中尾部）与时间范围。数据缺失时不得虚构；改为“待确认”，并下调可信度。

## 双层数据规则

- 头部数据验证层（25 分）：验证市场需求、核心出单词、价格锚点和用户痛点；不得单独用于判断新卖家可进入。
- 新卖家进入层（75 分）：以中腰部／尾部卖家的销量、价格、评分门槛、广告竞争和退货风险为主；这是主推结论的主要依据。

## 关键词与广告规则

- 以头部 ASIN 的高相关、可转化出单词建立词池；无效曝光词进入否词建议，不计作需求。
- 对每个核心投放词返回月/周搜索量、出单表现或转化信号、PPC 最低/建议/最高竞价，以及是否属于 ASIN 的点击前三。
- 使用以下公式评估广告承受力：`最高可承受 CPC = 售价 × 目标 ACoS × 预期广告转化率`。
- 数据允许时，计算达到目标 ACoS 所需的最低转化率：`建议 CPC ÷ (售价 × 目标 ACoS)`。
- 未提供成本、目标 ACoS 或新卖家预期广告转化率时，使用 30% ACoS 与保守 8% 广告转化率作为显式的临时基准，并提示该假设。

## 决策规则

- 70 分及以上、进入层至少 52/75 且没有硬适配风险：主推。
- 60–69 分：小批测试。
- 60 分以下：暂不立项。
- 型号、尺寸、螺纹、OEM 号等硬适配项未确认时，无论总分都不得主推。

## 输出结构

1. 产品识别与数据可信度。
2. 评分表及逐项依据。
3. 关键词／CPC 表：主投词、测试词、否词。
4. 评论分析：卖点、问题、能否通过产品或页面解决。
5. 主推结论、执行规格与下一步待确认项。

## 验证

使用一个 ASIN（如 B0BV241H3F）检查：输出能分辨相关出单词和无效曝光词，显示 PPC 区间，且不会把网页端或 API 权限不足误报为零需求。
