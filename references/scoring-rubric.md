# 评分刻度

使用实际证据选择下列区间。每项在区间内的具体分数必须说明相邻档位为何不适用。

## 覆盖率

`数据覆盖率 = 有有效证据的维度满分合计 ÷ 100`

- 无证据或只有未经核验推断：记 `N/A`，不记 0 分。
- 反面证据明确：可记低分或 0 分。
- 覆盖率不足 70%：只输出预评分和数据受限结论。
- 覆盖率不足 70%：正式总分和进入层总分均写 `N/A`，另行展示“已评分分数/已覆盖满分”。
- 覆盖率达到 70% 后，正式总分按 100 分制报告；未覆盖项保持 `N/A`，不要把已覆盖维度重新缩放至 100。

## 头部验证层

### 头部需求验证（15）

| 分数 | 标准 |
|---:|---|
| 0–3 | 多项来源显示需求很弱、明显衰退或高度偶发 |
| 4–7 | 有需求但集中于单一 ASIN、短期活动或强季节窗口 |
| 8–11 | 多个独立 ASIN 有稳定需求，90天表现可重复 |
| 12–15 | 需求稳定或增长，12个月趋势健康，来源和关键词均分散 |

### 头部关键词与用户痛点（10）

| 分数 | 标准 |
|---:|---|
| 0–2 | 主要流量词不相关、无效曝光占主导或点击/转化高度垄断 |
| 3–5 | 有少量相关词，但转化弱、集中度高或用户痛点不明确 |
| 6–8 | 多个高相关词有购买信号，并发现可验证的重复痛点 |
| 9–10 | 词路分散、转化稳定，痛点高频且可被产品或页面解决 |

## 新卖家进入层

### 中尾部卖家出单与价格带（15）

| 分数 | 标准 |
|---:|---|
| 0–3 | 中尾部无持续出单，主要依赖深度折扣或价格跌破可行区间 |
| 4–7 | 仅少数产品偶发出单，价格波动或断货影响明显 |
| 8–11 | 至少 3 个独立中尾部 ASIN 在90天内持续出单且价格可行 |
| 12–15 | 至少 5 个独立中尾部 ASIN 持续出单，价格带稳定且新品也能获得订单 |

### 新卖家 CPC／广告可行性（15）

使用 `scripts/calc_cpc.py` 的成本约束的可承受CPC精确结果；必须传入广告前利润和目标单件利润。任一项缺失时记 `N/A`，不得以售价乘目标 ACoS 代替。

| 建议CPC ÷ 可承受CPC | 基础分 |
|---:|---:|
| `<= 0.75` | 15 |
| `> 0.75` 且 `<= 1.00` | 12 |
| `> 1.00` 且 `<= 1.25` | 8 |
| `> 1.25` | 3 |

按近30天广告竞品数扣分：

| 广告竞品数 | 扣分 |
|---:|---:|
| 0–50 | 0 |
| 51–100 | 1 |
| 101–200 | 2 |
| 201以上 | 3 |

竞品数缺失时不扣分，但降低可信度。以用户目标为主；用户未提供时，以基准情景（30% ACoS、5%转化率）作为CPC维度正式分，保守与激进情景只作为敏感性分析。三个情景都必须标为假设。

### 竞争与评论门槛（10）

| 分数 | 标准 |
|---:|---|
| 0–2 | 品牌/父体高度集中，中尾部评论壁垒极高，低评论产品不出单 |
| 3–5 | 集中度中高，少量低评论产品出单但不稳定 |
| 6–8 | 多个品牌和低评论产品稳定出单，进入窗口可见 |
| 9–10 | 市场分散，新品/低评论产品持续获得自然或广告订单 |

### 利润空间（15）

使用 `scripts/calc_unit_economics.py` 的基准情景广告后贡献率：

| 贡献率 | 分数 |
|---:|---:|
| `<= 0%` | 0 |
| `> 0%` 且 `< 5%` | 3 |
| `5%–<10%` | 6 |
| `10%–<15%` | 9 |
| `15%–<20%` | 12 |
| `>=20%` | 15 |

成本缺失时记 `N/A`。不得用售价减采购价代替贡献利润。

### 适配、性能与退货风险（10）

| 分数 | 标准 |
|---:|---|
| 0–2 | 路由必需的适配、额定性能、安全或服务条件未知，或评论显示严重误购/失效且不可控 |
| 3–5 | 部分型号、尺寸或性能已知，但缺少关键接口、样品测试、耐久、认证、保修或反向物流证据 |
| 6–8 | 产品路线要求的规格完整，样品与额定工况核验，说明书/适配表清楚，退货和服务方案可执行 |
| 9–10 | 完整身份与性能证据、批次/耐久验证、低误购设计、合规文件、备件保修和反向物流均已验证 |

### 差异化空间（5）

| 分数 | 标准 |
|---:|---|
| 0 | 无可见差异化 |
| 1 | 仅颜色、文案或不可验证宣称 |
| 2 | 可通过适配表、图片或说明书改善 |
| 3 | 有一个可验证的产品、套装或包装改进 |
| 4 | 有两个以上可验证改进且供应链可实现 |
| 5 | 改进直接对应高频痛点，并已有样品或测试验证 |

### 评论质量（5）

该分数衡量“评论揭示的进入机会质量”，不是平均星级。

评分前必须确认评论属于目标子体/变体；父体总评分、总评论和其他变体评论不得作为目标变体的分母。卖家精灵分析报告出现变体归属冲突、空图表或缺失字段时，该维度记 `N/A`，而不是按 0 分或父体平均值处理。

| 分数 | 标准 |
|---:|---|
| 0 | 高频严重缺陷不可修复或涉及安全/合规 |
| 1 | 产品本体缺陷占主导，修复成本或可行性不明 |
| 2 | 严重问题与可修复问题混合，或跨变体/过期样本导致不确定 |
| 3 | 主要问题清晰，至少一项可通过产品或页面稳定修复 |
| 4 | 多个高频问题可修复，且近期/变体证据一致 |
| 5 | 痛点高频、严重度可控、解决方案已由样品或测试验证 |

## 决策

| 条件 | 结论 |
|---|---|
| 总分 ≥70、进入层 ≥52、覆盖率 ≥70%、全部硬门槛通过 | 主推 |
| 总分 60–69，或有非致命待验证项 | 小批测试 |
| 总分 <60 | 暂不立项 |
| 覆盖率 <70% | 数据受限，仅预评分 |
| 任一硬门槛未通过 | 不可主推 |
